# Full Qwen/Cosmos joint experiment

User-approved scope: Qwen3-VL-4B visual encoder and language backbone, Cosmos-Predict2.5-2B video transformer, fusion adapters, and ActionDiT all train. Wan VAE and the independent Cosmos text encoder stay fixed. Initialize both backbones from their original pretrained releases and fusion/action from seed42. Never load the old66k/70k experimental weights.

Reference: examples/LIBERO/train_files/run_libero.sh: all40tasks,80,000 optimizer updates,5,000 warmup,global batch256,ZeRO2,backbone LR1e-5/action LR1e-4,uniform video flow matching,extraction layer17. This experiment uses16nodes×16PPU,per-device1,accumulation1. Qwen LR1e-5;fusion/action LR1e-4;cosine floor5e-7;BF16;AdamW(.9,.95),eps1e-8,decay1e-8;clip1;four action diffusion repeats. Checkpointing is chosen after PPU memory/speed measurement.

The old frozen-feature experiment detached both backbone features at fusion. This experiment removes those stops: action loss reaches Qwen vision/language and Cosmos, while video loss trains Cosmos. The changed Cosmos action-gradient route is an additional experimental variable; any gain alone cannot establish that frozen Qwen was the sole cause of branch dominance.

Use CurrentImageLibero: retain the frozen VAE posterior/target/text cache, labels and equal-suite sampler; discard cached Qwen embeddings. Each sample provides only its current primary+wrist mosaic to online Qwen. Future target latents enter video_loss only. The image sidecar validates every sample identity and checks exact pixels against established preprocessing; its manifest records source provenance. The legacy float range-check behavior is preserved to avoid silently changing inputs. Uint8 dark images are decoded with explicit byte scaling.

Validation gates: optimizer includes every trainable tensor exactly once; action-only backward reaches Qwen visual+language and Cosmos; first distributed backward reaches every trainable tensor with finite gradients; parameter anchors in all five components update on every rank; nonfinite loss/norm aborts. Unit tests cover gradient boundaries, checkpoint recomputation, stale cache/future-image rejection, optimizer coverage, and prior evaluation protocols. Smoke checkpoint includes the trained Qwen under qwen.*, and must restore model/optimizer/RNG before production.

Save inference weights every5,000 updates; keep the latest two complete optimizer/RNG snapshots. Main experiment does not create a100-step inference checkpoint. The first recovery state is saved at100updates, then every500updates; retain two complete states. Formal inference weights remain every5,000updates. Recovery manifests publish only after all model/optimizer/RNG files exist. Platform-eviction retries reuse the latest published state and archive unsaved metric rows before replay. Use immutable code/config bundles for DLC and archive job request, response, validation, measured throughput/memory. Retain the existing local attribution evaluation and GPU15 keepalive.
